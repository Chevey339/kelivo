# C29 试用反馈修正与原生复核

本轮承接 C28，针对用户 2026-10-25 提供的 13 张截图继续修正，不将 C28 的检查记录当作本轮验收。原型来源仍为 `/Users/psyche/Downloads/kelivo-genui`，并采用用户本轮对函数图、Web 说明和展开返回的明确调整。

## 交互与外观

- 横向表格移除继承自 iOS 页面的 safe-area padding，滚动条落在表格下方的预留区，避免覆盖最后一行；保留横滚、圆角、筛选和单行分页。横滚后向上拖仍交给消息纵向滚动。
- 紧凑 IosFormTextField 统一 44dp 命中区和 36dp 填充外观。修正 InputDecorator 的 dense 排版仅撑大外框而文字仍靠上的问题；无附件、搜索前缀和数字加减都按同一行框居中。默认非 compact 调用不变。
- 图表选中值提示去掉叠加的上下留白，关闭按钮保留 44dp 命中区。图表/数据分段减少横向内边距，图例图形和文本按一致基线排版。
- 环图中心显示名称、数值+单位、百分比；长单位有宽度与单行省略约束，数值保留可用宽度。大字号时扩大圆心，不缩文字。
- `@sample` 函数折线/面积图不绘制常驻采样圆点，保留全部线顶点、点选位置、选中反馈和孤立有效点；普通观测数据与散点图保留标记。来源跟随本次实际求值的数组，条件的未执行分支不影响呈现，跨计算批次复用保留来源元信息。
- 坐标刻度只抹平相对步长的零点转换残差，原始数值、非常小的真实数据、冻结上下文均不改变。
- Badge 和 Callout 调整文字行框与图标对齐，带标签的 Divider 延伸到容器两侧。
- 展开时以 GlobalKey 在同一帧转移同一棵控件树，消息占位保持原高度；返回时保留 EditableTextState、光标、组字草稿和图表选择，不重新创建整卡。只有值改变的结果节点做 160ms 短暂淡入；输入与未变化内容不闪动，减少动效时关闭。未操作任何控件也能用 Esc 关闭。
- Web 卡片把源码图标与紧凑“打开”放在标题行。预览页只有单行标题、关闭和信息按钮，常驻沙盒副标题/CSP 栏移入“预览说明”对话框，保留底部系统安全区。Web 隔离策略、关闭清理和全应用单预览约束不变。
- “更多”使用左对齐的图标操作列表；页大小弹窗显示当前选择；替换/合并对话框区分确认与取消。均沿用现有应用对话框，不新增桌面底部弹层。
