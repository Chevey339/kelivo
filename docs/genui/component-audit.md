# C28 全组件视觉与交互复核

本次以用户的第二轮试用反馈、原始技术计划、HANDOFF 和
`/Users/psyche/Downloads/kelivo-genui` 的 DESIGN.md、原型和 PNG 为依据。
最新用户要求明确替代原交接中的消息高度上限和常驻图表统计说明：消息内
完整展示组件，由消息列表负责纵向滚动；详细统计保留在无障碍语义中。

## 当前行为

- 消息里的 Surface 不设高度上限，不创建内部纵向 Scrollable，不截断内容。
  展开仍是可选的专注视图，和消息共享状态；关闭后焦点返回触发按钮。
- 设置 → 显示 → 渲染提供“显示交互界面标题栏”，默认开启。关闭后保留
  状态提示和底部小型更多入口，源码、展开、附带、导出和重置仍可访问。
  开关、主题和字号变化不清空输入。
- 输入框约 36dp 的填充外观放在至少 44dp 的交互区域内；加减、关闭和头部
  图标的按下底色收为 28dp。按钮保留 36dp 外观和 44dp 移动端命中区。
  使用既有 IosFormTextField / IosIconButton 的显式可选参数，其他调用默认不变。
- 短表格以及筛选后不超过 10 行的表格不显示分页栏。长表格的范围、页大小、
  翻页组成同一行；选择 20 行后只有一页时隐藏无效的前后箭头。
  圆角裁切、空值置底、筛选高亮、窄屏横滚保持有效。
- 环形饼图（donut）选中项的名称、值、单位和百分比显示在圆心；未选中时显示合计。
  不再重复显示图外提示框。数值呈现去除计算尾差，保留有意义的小数和整数差异；
  输入提交、冻结上下文和图形计算仍使用原数据。
- 图表删除常驻的“几个系列、几行数据、0 个缺失”长说明。无障碍摘要仍完整；
  实际缺值、定义域缺口仍有可见提示。坐标使用易读刻度；单位只在标题明确
  标注同一单位时去重，英文单词中的单个字母不能吞掉单位。
- 图例整项可点击，隐藏系列用删除线表达；键盘才显示外框焦点环。
  柱形采用圆角实色，保留小型形状标记，系列识别不单靠颜色。
- 输入框里的附带状态收为紧凑卡片，去掉重复标题，整行可展开。
  准确发送文本放在独立的等宽预览中，限制预览高度；原始冻结文本不变。
  失效状态仍播报，替换/合并仍使用现有居中对话框。
- 流式占位使用虚线边框、等待信息和大块扫光填充；Chart 保持 200dp 高度。
  各占位共享时钟，完成、中断和系统减少动效时停止动画。

## 取消高度限制的测量

`tool/genui_inline_profile_bench.dart` 是手动运行、仅打印的实验，旧高度包装
只存在于该比较夹具中。macOS 26.5.2 / M4 Pro / 120 Hz / profile 模式，12 个
Surface，每个包含 501 点图表和额外 16 个 Metric；相同组件有界/完整高度交替
各三轮，每轮预热往返 6 秒后测量 6 秒。测量 build/raster 独立阶段，不相加。

完整高度三轮 build p95 为 404 / 411 / 341 µs，raster p95 为
1077 / 1108 / 839 µs，2166 个测量帧中没有超出 8.33ms 阶段预算的帧。
有界对照 2167 帧中有 1 帧超预算；该夹具没有发现移除高度限制带来的回退。
进程峰值 RSS 约 182.4 MiB。日志：`build/genui/c28-inline-profile.log`。

这只比较当前组件包装，滚动相同距离经过的组件数量不相同，不能据此声称生产长
历史 ±3% 等价，也不能推广到 Android 或全部机型。之前用户接受的 Android
120Hz 性能限制仍有效；本轮没有重跑该设备性能或付费模型评测。
